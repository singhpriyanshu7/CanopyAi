# 🌳 CanopyAI

### Plant Smart. Prevent Damage.

CanopyAI is an AI-assisted urban tree planning system that analyzes a specific road or street location and recommends tree species based on available space, surrounding infrastructure, root behavior, climate conditions, and long-term growth.

Instead of simply asking **"Which tree should we plant?"**, CanopyAI asks:

> **"Which tree can safely coexist with this specific street?"**

---

## 🚀 Key Features

- 📍 **Interactive Map** — Select a real street location for analysis.
- 🗺️ **Location & Infrastructure Analysis** — Analyze available geographic and infrastructure constraints.
- 🌳 **Tree Compatibility Engine** — Evaluate tree species against site conditions.
- 🏆 **Top Tree Recommendations** — Get suitable species ranked by compatibility.
- ⚠️ **Infrastructure Risk Analysis** — Identify potential road, footpath, building, utility and root-related conflicts.
- 📌 **Recommended Planting Zone** — Visualize an estimated suitable planting area.
- 💡 **Explainable Recommendations** — Understand why a particular tree was recommended.
- 🤖 **AI-Assisted Explanation** — Gemini converts structured recommendation data into a human-readable explanation.
- 🌱 **0–10 Year Growth Visualization** — Explore potential future tree growth.
- 🛠️ **Mitigation Recommendations** — Identify possible measures for reducing infrastructure conflicts.
- 📊 **Compatibility Breakdown** — View infrastructure, root, climate and space-related compatibility.
